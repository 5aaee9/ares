# Processor output isolation

## Decision and source boundary

This bounded correction implements ARD-0021/ARD-0023, not full parity acceptance.
Upstream is OrcaSlicer 2.4.2, commit
`8500fcdccaa10b5099ac20d252af3a7c560046f1` (read-only).
`src/libslic3r/GCode.cpp::GCode::GCodeOutputStream::write` passes generated
text to `GCodeProcessor::process_buffer` (GCode.cpp:6262).
`src/libslic3r/GCode/GCodeProcessor.cpp` owns `process_buffer` (2677),
`run_post_process` (981), `process_G2_G3` (4548), and `calculate_time` (5951).
The Rust destination is `ares-core/src/project_slice/gcode_emit/processor.rs`
and its ordinary child modules. Its input is the generated byte vector and
explicit processor parameters, never ambient environment or filesystem input.

Included: delete `ARES_ESTIMATE_ONLY` substitution and the four processor-local
dump gates (`ARES_DUMP_LMAP2`, `ARES_DUMP_EBLOCKS`, `ARES_DUMP_LMAP`,
`ARES_DUMP_TIMES`), including instrumentation-only work. Retain processing,
progress placement, time/filament replacement, motion order, arithmetic and
planner scheduling unchanged. Split the existing estimator/accounting and
motion-limit responsibilities into modules below 400 physical lines.
No alternate input API, permanent debug flag, fallback, or source include
splitting is introduced. Tests live separately from production implementations.

Deferred: additional upstream processor behavior, planner/timing parity fixes,
router/fill ordering, other production debug hooks, all-printer legal option
coverage, and complete Orca artifact parity. Existing estimator code remains a
temporary compatibility shell around the cited upstream owner; this change does
not establish its full equivalence. `libvgcode` rendering-neutral data ownership
remains in `ares-vgcode`; no viewer data or runtime change is included.

## Validation boundary

A committed CLI regression must fail before deletion: a child `Command` sets
`ARES_ESTIMATE_ONLY` to a sentinel file while slicing a real 3MF. Tests compare
complete bytes against the same CLI with processor environment variables unset,
normalizing only one independently validated generator timestamp line. Missing
and existing non-file paths must be irrelevant after deletion; dump paths must
neither be created nor modified. No global test environment mutation is allowed.

The small project fixture is copied byte-for-byte from the Coordinator anchor
(SHA256 `200980b8217b4a5f0dfb8022e0a837c662c15fcaaaeca7d7a545eb7be250a63d`).
The verified pre-fix binary (base `431fb361`) is labelled baseline evidence, not
current-build identity. Preserve raw baseline/candidate/real Orca outputs,
commands and hashes externally. Compare baseline and candidate using only the
validated generator line normalization, and preserve the full Orca residual
diff without weakening any comparator or claiming a match.

Tier 1 remains browser-WASM, Windows, macOS and Linux. Local WASM core/adapter
compilation and Linux CLI/core tests are bounded evidence, not native Windows,
macOS or browser runtime certification. Unrelated known failures (including KSR
filament 11335.74 vs 11335.55) must not be hidden by changed expected values.
